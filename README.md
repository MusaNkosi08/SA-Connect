# SA-Connect

<img width="1600" height="900" alt="image" src="https://github.com/user-attachments/assets/cabe40b8-38c5-4758-a49c-ed5bdf2f19eb" />


SA Connect is a futuristic, South African–themed content directory built with 
pure HTML, CSS and vanilla JavaScript (no frameworks).

It lets users search and filter 24 curated places across Johannesburg, Cape Town, 
Durban, Pretoria and Stellenbosch by category and location. Cards load real, 
location-matched images from Unsplash, and users can star favourites that persist 
via localStorage. Includes a "⭐ Favourites only" filter, plus proper loading, 
empty and error states — and a validated contact form.
